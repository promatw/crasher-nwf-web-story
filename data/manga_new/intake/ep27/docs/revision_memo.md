# JP27 revision_memo.md

## Key decisions

- JP27 is packaged as a color test / color clean art candidate.
- No image was regenerated or modified during packaging.
- 001–003 selected are the first generation versions re-uploaded and identified by HM:
  - d81 -> c_nwf_ch02_ep27_001_p01a_art_v01.png
  - f41 -> c_nwf_ch02_ep27_002_p01b_art_v01.png
  - bca -> c_nwf_ch02_ep27_003_p02a_art_v01.png
- The second generated 001–003 set is not selected and is stored under art/rejected/ as rejected_reference.

## Rejected / reference reasons

- 002 second generation: vehicle body was elongated and launch angle was not ideal.
- 003 second generation: falling angle was not ideal; stone giant expression felt less lively.
- Earlier 010 / 011 candidates were not selected after HM marked removal / cleanup issues; selected versions are stored in art/selected.

## Size note

- 001–003 selected actual size: 864 × 1536.
- 004–015 selected actual size: 941 × 1672.
- Package is not normalized to 864 × 1536.
- If UXE1 decides to normalize, normalize all selected art in one pass and do not mix normalized and non-normalized outputs.
